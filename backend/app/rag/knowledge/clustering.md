# Clustering

Clustering is an unsupervised learning task that groups similar data points
together without using labeled target values. It is used for customer
segmentation, anomaly grouping, and pattern discovery.

Common algorithm: K-Means, which partitions data into k clusters by minimizing
within-cluster variance. The number of clusters (k) must be chosen in advance,
often using the elbow method or silhouette score.

Clustering assumes features are on comparable scales, so standardization is
usually applied first.
