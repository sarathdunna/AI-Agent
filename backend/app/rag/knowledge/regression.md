# Regression

Regression is a supervised machine learning task where the goal is to predict a
continuous numeric value (e.g. price, temperature, sales) from input features.

Common algorithms: Linear Regression, Ridge, Lasso, Decision Tree Regressor,
Random Forest Regressor, Gradient Boosting Regressor.

Key evaluation metrics: MAE, MSE, RMSE, R-squared.

Use regression when your target variable is numeric and continuous (not a
category), and when the number of distinct values is high relative to dataset size.
